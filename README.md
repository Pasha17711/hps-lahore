# HPS Lahore

Production website for HPS Lahore, designed and developed to modernize the school's digital presence and make key information easier to access across desktop and mobile.

## Live Website

https://hpslahore.com

## Highlights

- Responsive design across desktop, tablet, and mobile
- Admissions information and inquiry flow
- Academic results and achievements
- Leadership and school information
- Direct WhatsApp inquiry integration
- Custom animations and interactive UI
- SEO support with sitemap and robots configuration
- Deployed with Vercel and connected to a custom domain

## Tech Stack

- HTML
- CSS
- JavaScript
- Vercel
- Git & GitHub

## Role

Designed, developed, and deployed the website end-to-end, including UI/UX implementation, responsive behavior, deployment, DNS configuration, and ongoing production updates.
